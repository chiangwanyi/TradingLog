## 初始化 TradingLog 前端工程（Vue 3 + JavaScript + Naive UI）

在 `E:/Data/projects/TradingLog` 从零搭建前端脚手架，技术栈：Vue 3.5 / Vite 8 / Vue Router 5 / Pinia 4 / Naive UI 2.45，纯 JavaScript（无 TypeScript）。

### 关键决策

- **按需引入**：组件走 `unplugin-vue-components` + `NaiveUiResolver`；组合函数走 `unplugin-auto-import`（`vue`、`vue-router` 预设 + naive-ui 的 `useMessage/useDialog/useNotification/useLoadingBar`）。模板中写 `<n-xxx>` 即可，不做全局注册。
- **主题**：品牌色与明暗覆盖集中在 `src/theme/index.js`，经 `NConfigProvider` 的 `theme` / `theme-overrides` 注入；明暗模式由 Pinia `app` store 管理并持久化到 localStorage，首次进入跟随系统偏好。
- **Provider 与全局 API**：`useMessage` 等只能在对应 Provider 后代中调用，故新增 `src/components/NaiveApiBridge.vue` 在 Provider 内部把实例注册到 `src/utils/naive.js`，让路由守卫、请求拦截器等非组件环境也能使用。
- **路径别名**：`@` -> `src`（`vite.config.js` 的 `resolve.alias` + `jsconfig.json` 的 `paths`）。
- **涨跌配色**：遵循中国习惯，涨红 `#d03050` / 跌绿 `#18a058`，封装为 `.num-up` / `.num-down`。

### 版本选型注意

- Vue Router 5 官方定位为「过渡版本」，把 unplugin-vue-router 合并进核心包；对未使用文件路由的 v4 用户**无破坏性变更**，因此本次直接采用 v5 的 v4 风格 API。
- Vite 8 要求 Node `^20.19.0 || >=22.12.0`。

### 验证结果

- `npm install` 成功（109 个包，0 漏洞）。
- `npm run build` 成功：2689 个模块，路由级分包正常（各 view 与 layout 独立 chunk）。
- 产物静态校验：无 `resolveComponent("n-...")` 回退、无残留 `n-*` 原生标签，11 个目标组件均被静态解析并打包。
