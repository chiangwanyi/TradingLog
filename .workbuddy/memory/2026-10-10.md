## 初始化 TradingLog 前端工程（Vue 3 + JavaScript + Naive UI）

在 `E:/Data/projects/TradingLog` 从零搭建前端脚手架，技术栈：Vue 3.5 / Vite 8 / Vue Router 5 / Pinia 4 / Naive UI 2.45，纯 JavaScript（无 TypeScript）。

### 关键决策

- **按需引入**：组件走 `unplugin-vue-components` + `NaiveUiResolver`；组合函数走 `unplugin-auto-import`（`vue`、`vue-router` 预设 + naive-ui 的 `useMessage/useDialog/useNotification/useLoadingBar`）。模板中写 `<n-xxx>` 即可，不做全局注册。
- **主题**：品牌色与明暗覆盖集中在 `src/theme/index.js`，经 `NConfigProvider` 的 `theme` / `theme-overrides` 注入；明暗模式由 Pinia `app` store 管理并持久化到 localStorage，首次进入跟随系统偏好。
- **Provider 与全局 API**：`useMessage` 等只能在对应 Provider 后代中调用，故新增 `src/components/NaiveApiBridge.vue` 在 Provider 内部把实例注册到 `src/utils/naive.js`，让路由守卫、请求拦截器等非组件环境也能使用。
- **路径别名**：`@` -> `src`（`vite.config.js` 的 `resolve.alias` + `jsconfig.json` 的 `paths`）。
- **涨跌配色**：遵循中国习惯，涨红 `#d03050` / 跌绿 `#18a058`，封装为 `.num-up` / `.num-down`。

### 版本选型注意

- Vue Router 5 官方定位为「过渡版本」，把 unplugin-vue-router 合并进核心包；对未使用文件路由的 v4 用户**无破坏性变更**，因此本次直接采用 v5 的 v4 风格 API。
- Vite 8 要求 Node `^20.19.0 || >=22.12.0`。

## 新增后端模块 server/（FastAPI + uv）

用户要求：在项目目录下新建后端文件夹，用 uv 初始化 Python 项目充当后端服务。经确认，采用 **FastAPI** + 文件夹名 **`server/`**。

### 环境

- `uv 0.12.17`（`C:\Users\jiang\.local\bin\uv`），Python 3.13 由 uv 管理。
- 初始化命令：`uv init server --app --name tradinglog-server --python 3.13 --managed-python --vcs none --no-description`
  - 注意：`uv init --app` 默认生成 **src-layout + uv_build 打包后端**（不是扁平 main.py），包名按项目名推导为 `tradinglog_server`。

### 关键决策

- **包名改为 `app`**（导入路径 `app.xxx` 更简洁）。因为包名与项目名不一致，必须在 `pyproject.toml` 显式声明：
  ```toml
  [tool.uv.build-backend]
  module-name = "app"
  module-root = "src"
  ```
  否则 uv_build 找不到 `src/tradinglog_server/` 会构建失败。
- `--vcs none`：避免生成嵌套 git 仓库（根目录统一管理）。
- 分层结构：`src/app/main.py`（应用工厂 create_app + ASGI 实例）、`core/config.py`（pydantic-settings 配置中心）、`api/v1/router.py`（路由汇总）、`api/v1/endpoints/*.py`（业务接口，目前只有 health）、`tests/`（conftest + 冒烟测试）。
- 依赖：运行时 `fastapi` / `uvicorn[standard]` / `pydantic-settings`；开发依赖走 PEP 735 的 `[dependency-groups].dev`：`pytest` / `ruff` / **`httpx2`**。
  - 注意：starlette 1.7 起 `starlette.testclient` 已弃用 `httpx`，改用 **`httpx2`** 可消除弃用告警；`httpx` 已从 dev 依赖移除。
- 新增 `server/.gitignore`（忽略 `.venv/`、`__pycache__/`、`.env`、各类缓存），`.env.example` 提交、`.env` 不提交。
